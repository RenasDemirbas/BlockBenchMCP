How it works

Two files, one local connection

Your MCP client starts the server. The plugin inside Blockbench dials into it, so Blockbench never asks for network access, and the connection never leaves your computer.

Install

Running in three steps

Download

Get blockbench_mcp.js and mcp-server.js from the latest release. Keep them in a folder that stays put.

Load the plugin

In Blockbench: File → Plugins → Load Plugin from File, then pick blockbench_mcp.js.

Register the server

claude mcp add --scope user blockbench -- node /path/to/mcp-server.js

Other clients: see the docs.

Safe by design

Local, undoable, quiet

Local onlyThe bridge listens on 127.0.0.1 and refuses connections from websites.
Undo anythingEvery tool writes to Blockbench's undo history. Ctrl+Z takes a step back.
