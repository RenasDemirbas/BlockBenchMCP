Recipes

Each recipe shows what to ask for, then the tool calls the assistant makes for it. Asking in your own words is enough; the calls are here so you know what is possible and can ask for it precisely.

A walk cycle in two calls

Add a 1-second walk cycle: swing the left legs, then mirror them to the right side half a cycle later.
create_animation { "name": "walk", "length": 1, "loop": "loop" }

set_keyframes {
  "animation": "walk",
  "bones": [
    { "bone": "leg_fl", "channel": "rotation", "keyframes": [
      { "time": 0, "values": [-30, 0, 0] }, { "time": 0.5, "values": [30, 0, 0] }, { "time": 1, "values": [-30, 0, 0] } ] },
    { "bone": "leg_bl", "channel": "rotation", "keyframes": [
      { "time": 0, "values": [30, 0, 0] }, { "time": 0.5, "values": [-30, 0, 0] }, { "time": 1, "values": [30, 0, 0] } ] }
  ]
}

mirror_keyframes { "animation": "walk", "phase_offset": 0.5 }

Without mappings, mirror_keyframes pairs bones by their left/right names. +X rotation swings a hanging limb forward.

Shade a whole limb with one gradient

Darken the legs toward the paws, as one gradient over the whole leg.
paint_texture {
  "ops": [{
    "type": "gradient",
    "target": { "element": "legs", "faces": "all" },
    "space": "world",
    "stops": [ { "at": 0, "color": "#c9772f" }, { "at": 1, "color": "#4a2a17" } ]
  }]
}

space: "world" spreads the stops over the model's height, so a leg made of several cubes gets one smooth ramp instead of a band per cube. A group as the target covers every cube inside it.

Catch parts that float or clip during an animation

Check the walk for intersecting or floating parts at a few points in the cycle.
validate_model { "animation": "walk", "times": [0, 0.25, 0.5, 0.75] }

The result lists intersecting pairs, and parts that touch nothing in their own, parent, child or sibling bones, with the bone, the nearest neighbour and the gap in units.

A tail that bends instead of breaking

Rig the tail mesh with three bones from the base to the tip and make the joints soft.
add_armature {
  "name": "tail_rig",
  "bones": [
    { "name": "tail_1", "head": [0, 8, 4],  "tail": [0, 8, 10] },
    { "name": "tail_2", "head": [0, 8, 10], "tail": [0, 9, 16], "parent": "tail_1", "connected": true },
    { "name": "tail_3", "head": [0, 9, 16], "tail": [0, 11, 21], "parent": "tail_2", "connected": true }
  ],
  "meshes": ["tail"]
}

vertex_weights { "action": "smooth", "mesh": "tail", "near": { "bone": "tail_2", "distance": 3 } }
capture_screenshot { "angle": "east", "view_mode": "weighted_bone_colors" }

Bones are placed by where they start and end, in model units. The mesh is skinned in the same call; vertex_weights inspect reports any vertex that follows no bone.

Pull a nose out without creasing the face

Pull the front of the head forward by 2, softly.
transform_mesh {
  "mesh": "head",
  "select": { "facing": "north" },
  "ops": [{ "type": "move", "offset": [0, 0, -2] }],
  "falloff": { "radius": 4, "curve": "smooth", "distance": "connected" }
}

The selected faces move by 2; vertices within 4 units, measured along the mesh, move less the further away they are. "connected" leaves separate parts nearby untouched.

Material maps from the colour texture

Give the crate PBR maps: bumps from the paint, a matte surface, and metal where the grey bands are.
generate_pbr_map {
  "texture": "crate",
  "maps": [ { "preset": "normal_from_brightness" }, { "preset": "roughness_matte" }, { "preset": "metal_from_grey" } ]
}
capture_screenshot { "view_mode": "material" }

The maps go into the texture's material: a normal texture and one MER texture whose red, green and blue channels hold metalness, emissive and roughness. "list_presets": true lists the built-in presets and the ones you saved in Blockbench.

An 8-direction sprite sheet

Export the hop animation as an 8-direction isometric sprite sheet at 64 px with the pico8 palette.
pixel_art {
  "action": "export_sheet",
  "animation": "hop",
  "view": "isometric",
  "directions": 8,
  "size": 64,
  "palette": "pico8",
  "output": { "directory": "C:/Users/you/Desktop/slime", "name": "slime_hop" }
}

The sheet comes with Aseprite JSON and a fixed feet pivot. Ask for the presets action to see every view, style and palette.

Open a Java child model

Open assets/minecraft/models/block/oak_stairs.json from my resource pack.
project_file { "action": "open", "path": "C:/packs/mypack/assets/minecraft/models/block/oak_stairs.json" }

A child model that only names a parent opens with its whole parent chain merged into one editable model, with no question box. "resolve_parents": false opens the child alone.
